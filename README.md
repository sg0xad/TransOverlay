# TransOverlay

단축키로 화면 전체 또는 원하는 영역을 캡처해 **Google 번역**으로 번역한 뒤, 원문 위치 그대로 화면 위 오버레이로 자연스럽게 표시해 주는 Windows 데스크톱 프로그램입니다.

## 주요 기능

* **다국어 지원 (12개 주요 언어)**: 영어, 한국어, 일본어, 중국어(간체/번체), 스페인어, 프랑스어, 독일어, 러시아어, 베트남어, 태국어, 인도네시아어 선택 및 빠른 언어 전환(`⇄`) 지원
* **전체화면 / 영역 지정 캡처**: 전용 단축키로 전체화면 또는 마우스 드래그 영역만 선택해 번역
* **언어 팩 자동 대응 OCR**: PC에 설치된 Windows 내장 OCR을 우선 사용하고, 해당 언어 팩이 없으면 별도 설치 과정 없이 자동으로 클라우드 OCR로 전환
* **자연스러운 오버레이 렌더링**: 원문 배경색 보간 인페인팅과 원문 글자색 매칭으로 화면 위에 이질감 없이 표시
* **게임 호환 및 편의 기능**:
  * 테두리 없는 창모드(Borderless) 게임 위 최상단 표시 및 관리자 권한 실행 지원
  * **클릭 시 오버레이 닫기** ON/OFF 토글, 투명도 조절, 설정 변경 시 즉시 자동 저장·적용
  * 번역 영역을 가리지 않는 외부 분리형 컨트롤 바(`원본 비교 / 저장 / 닫기`) 및 시스템 트레이 상주

## 다운로드 및 실행 방법

### 방법 1. 실행 파일(`.exe`) 바로 사용 (권장)

1. 이 저장소의 **Releases** 페이지에서 최신 `TransOverlay.exe`를 다운로드합니다.
2. 별도 설치 없이 `TransOverlay.exe`를 더블클릭해 실행합니다.

> **참고**: 처음 실행 시 Windows SmartScreen 경고가 뜰 수 있습니다. 개인 빌드 프로그램으로 코드 서명이 없기 때문이며, **추가 정보 → 실행**을 눌러 시작할 수 있습니다.

### 방법 2. 소스 코드에서 직접 실행 또는 빌드 (Python 3.10+)

```bash
pip install -r requirements.txt
python screen_translate_overlay.py
```

직접 `.exe` 파일을 빌드하려면 폴더 안의 `build_exe.bat`를 실행하면 `dist\TransOverlay.exe`가 생성됩니다.

## 번역 속도 향상 팁 (Windows 언어 팩 설치 · 선택 사항)

언어 팩이 없어도 클라우드 OCR로 자동 번역되지만, 자주 번역하는 원본 언어의 **Windows 기본 언어 팩**을 설치해 두면 텍스트 인식을 외부 서버 대신 PC 내부에서 바로 처리하므로 **번역 속도가 훨씬 빨라지고 더 안정적**으로 동작합니다.

### Windows 11 설치 방법

1. **`Win + I`** 키를 눌러 **설정**을 엽니다.
2. 왼쪽 메뉴에서 **시간 및 언어** → **언어 및 지역**을 선택합니다.
3. **기본 설정 언어** 항목 오른쪽의 **언어 추가** 버튼을 클릭합니다.
4. 자주 번역할 원본 언어(예: `English (United States)`, `일본어`, `중국어(간체)` 등)를 검색해 선택하고 **다음**을 누릅니다.
5. **선택적 언어 기능**은 기본 선택 상태 그대로 두고, **내 Windows 표시 언어로 설정** 체크는 해제한 뒤 **설치**를 클릭합니다. (Windows 메뉴 언어는 한국어로 유지됩니다.)
6. 설치가 완료되면 시스템 트레이에서 `TransOverlay`를 완전히 종료했다가 다시 실행합니다.

## 게임 사용 시 참고사항

* 게임 디스플레이 설정을 **테두리 없는 창모드(Borderless Fullscreen)** 또는 **창모드**로 두어야 게임 화면 위에 오버레이가 표시됩니다.
* 관리자 권한으로 실행되는 게임에서 단축키가 동작하지 않으면, 프로그램 상단의 **관리자 실행** 버튼을 눌러 다시 시작해 주세요.
